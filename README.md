Medify is a a React-based web application that allows users to find medical centers in a specific state and city across the USA and book appointments.

Features

1. **Landing Page**: A top navigation bar provides access to platform sections like Find Doctors, Hospitals, Medicines, and more, with a search section for selecting state and city to list medical centers via an API.
  
2. **Search Results Page**: Displays a list of available medical centers in the selected location with an option to book appointments.

3. **Booking Interface**: A detailed booking section allows users to choose a medical center, select an appointment date within a week, and pick a time slot.

4. **My Bookings Page**: A personalized page shows all user bookings with medical center details, appointment date, and time.

5. **Responsive Design**: The application is fully responsive, adhering to design standards from the Figma screenshots.

Cloning and Running the Application

To clone the repository and run the Expense Tracker application locally, follow these steps:

Clone the repository from GitHub:
git clone https://github.com/Srishti918/medify-app.git

Navigate to the Expense Tracker directory: cd medify-app

Install dependencies using npm: npm install

Start the application: npm run dev

The application will start running on http://localhost:5173 in your default web browser.
